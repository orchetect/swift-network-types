# SwiftNetworkTypes

[![](https://img.shields.io/endpoint?url=https%3A%2F%2Fswiftpackageindex.com%2Fapi%2Fpackages%2Forchetect%2Fswift-network-types%2Fbadge%3Ftype%3Dplatforms)](https://swiftpackageindex.com/orchetect/swift-network-types) [![](https://img.shields.io/endpoint?url=https%3A%2F%2Fswiftpackageindex.com%2Fapi%2Fpackages%2Forchetect%2Fswift-network-types%2Fbadge%3Ftype%3Dswift-versions)](https://swiftpackageindex.com/orchetect/swift-network-types) [![License: MIT](http://img.shields.io/badge/License-MIT-lightgrey.svg?style=flat)](https://github.com/orchetect/swift-network-types/blob/main/LICENSE)

Provides network value types for Swift with data introspection and validation methods.

- `DomainName`
- `ReverseDomainName`
- `IPAddress`
- `EmailAddress`

## Getting Started

This library is available as a Swift Package Manager (SPM) package.

1. Add the **swift-network-types** repo as a dependency.

   ```swift
   .package(url: "https://github.com/orchetect/swift-network-types", from: "1.0.0")
   ```

2. Add **SwiftNetworkTypes** to your target.

   ```swift
   .product(name: "SwiftNetworkTypes", package: "swift-network-types")
   ```

3. Import **SwiftNetworkTypes** to use it.

   ```swift
   import SwiftNetworkTypes
   ```
